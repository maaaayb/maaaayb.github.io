FeaturedWeb app · Team tool · Prospecting

LG Contact Hub

Problem: The lead gen team sourced school contacts in Clay, then copy-pasted them into a shared Google Sheet every day to find emails and check if each person still worked there. Slow, cluttered and easy to get wrong.

Built: A password-protected web app that replaces the sheet. A teammate pastes their Clay table link and the hub pulls the finalized contacts through Clay's API into their own workbook, one list per daily batch, then finds emails, verifies employment and sorts the results automatically.

Paste Clay link→Clay API→Skrapp email lookup→Serper employment check→Sorted list per teammate

Auto-updating Meeting Booked dashboard

Problem: Conference meetings were booked on a teammate's calendar, and nobody had a live view of the count.

Built: Make writes each booking to a sheet, GitHub Actions rebuilds a password-protected page, and Cloudflare R2 hosts it, on a shared bot account so it never depends on one person's login.
